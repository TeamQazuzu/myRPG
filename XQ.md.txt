# 正文


## 一、设计哲学

> **“留白越多，想象越大，上限越高。”**

- 纯文字RPG，跨平台，轻量化
- 陪伴型节奏，不设体力限制
- 死亡有代价，重玩有价值
- 核心乐趣 = **运气 + 策略 + 经验**
- **永远不让玩家知道自己走了多远**


## 二、世界观与叙事总纲

### 核心设定

> **“世界被分割成一个一个的牧场。组织在圈养所有人。而人们对自己的命运一无所知。”**

- 组织把世界分割成无数小区域
- 每个区域由60级机械守卫封闭式圈养
- 被圈养者产出资源的99%被组织攫取
- 被圈养者生活极端困苦

### 组织理念（宣传）

“聪明人管理世界，以确保资源合理使用、人人平等、人人有饭吃。”

### 组织实质

剥削、垄断、控制、圈养。资源单向流动：底层产出 → 组织消耗。

### 世界结构（五层）

| 层级 | 名称 | 定位 | 实质 |
|------|------|------|------|
| 第一层 | 灰烟村 | 新手村 | 牧场起点，资源产出 |
| 第二层 | 灰烬镇 | 第一个城镇 | 资源初级加工 |
| 第三层 | 灰烬矿场 | 核心区域 | 资源精炼、中转 |
| 第四层 | 新世界（组织世界）| 组织所在地 | 资源消耗终端 |
| 第五层 | 浮空塔 | 总部 | 主人的餐桌 |

### 叙事文风

- **史诗**：守门员登场、重大事件
- **日常低语**：酒馆对话、环境描写
- **战斗纪实**：简洁、有力


## 三、父母的故事

### 两对父母

主角的父母（埃德蒙 & 莉娜）与艾琳的父母，曾是组织的中层管理者——同事、好友、同谋。

### 他们做了什么

- 共同收集了足以证明组织运作方式的证据
- 试图迫使组织上层做出改变，被警告“再多事就杀你全家”

### 他们如何保全孩子

- 两对父母同时做出选择：**一起消失，换取两个孩子平安长大**
- 组织接受交易，派遣一名40级看守持续监控
- **世人皆以为两对父母都死了。只有村长和极少数人知道真相。**

### 主角的认知

- 主角6岁，父亲说“出一趟远门”，再也没有回来
- 村里口径统一为“去世了”
- 男孩6岁记忆模糊，日常被酒馆琐事填满，从未深究

### 艾琳的认知

- 艾琳5岁，父母同样消失
- 女孩早熟、敏感、执念深，15年来一直在惦记、在寻找

### 传家宝

- 主角：**父亲的旧短剑**
- 艾琳：**父亲的旧弓**

### 主角在故事中的位置

从开局陪邻家女孩寻亲，到后来合并为同时也为自己寻亲，最后发现不是为了寻找父母，**是为了走完父母留下的那条路。**

## 八、战斗系统

### 核心原则

> **“四种伤害，四种状态。速度决定谁先动手。打先手，就是打优势。”**

### 伤害类型（4种）

| 伤害类型 | 对应异常状态 | 状态效果 |
|----------|-------------|----------|
| **物理** | 流血 | DOT，每回合损失生命，持续3回合 |
| **火焰** | 灼烧 | DOT，每回合损失生命，持续3回合（可叠加2层） |
| **冰霜** | 减速 | 技能冷却时间+1回合，持续2回合 |
| **雷电** | 僵直 | 起手速度-30%，持续1回合 |

### 异常状态详表

| 状态 | 触发方式 | 效果 | 持续时间 | 是否可叠加 |
|------|----------|------|----------|-----------|
| 流血 | 物理伤害暴击/特定技能 | 每回合损失攻击力×0.3的生命 | 3回合 | ❌ |
| 灼烧 | 火焰伤害命中/特定技能 | 每回合损失攻击力×0.4的生命 | 3回合 | ✅ 最多2层 |
| 减速 | 冰霜伤害命中/特定技能 | 技能冷却回合+1 | 2回合 | ❌ |
| 僵直 | 雷电伤害命中/特定技能 | 速度-30% | 1回合 | ❌ |

### 速度与出手顺序

- 每帧战斗开始前，系统根据所有单位的速度值排序
- 速度高者先出手
- 僵直状态：速度-30%，排序中被拉到后面

### 战斗规模

| 规则 | 限制 |
|------|------|
| 最多同时战斗单位 | **3 vs 6**（3名己方 vs 最多6名敌方） |
| 剧情多波次 | 2-4波，中间不可休整，每波独立计算30回合 |

### 回合上限

#### 日常战斗

| 规则 | 说明 |
|------|------|
| 每场战斗上限 | **30回合** |
| 30回合结束 | 强制**平局**，双方不死亡，退回上一帧 |
| 状态恢复 | 退回后HP/MP恢复至战前状态 |
| 不消耗复活 | 平局不属于死亡 |

#### 多波次战斗（剧情Boss）

| 规则 | 说明 |
|------|------|
| 触发 | 极少（Boss战/副本终局） |
| 波次 | 2-4波 |
| 回合上限 | **每波独立30回合** |
| 平局结果 | 退回**上一个安全帧** |
| 平局代价 | **HP=1，MP=0，随从残血，损失5-10%金币或材料** |
| 进度重置 | Boss战完全重置 |

> 多波次具体设计（波次数、敌人配置）留空，由剧情设计阶段补写。

### 战斗界面

- 敌人分前后两排，每排3个
- 状态图标飘在单位上方（最多3个）
- 血条直接显示在图标下方
- 出手顺序提示
- 状态总览汇总所有异常
- 日志精简（4行滚动）

## 十一、随从系统

- 5级解锁第1随从，10级解锁第2随从

## 十五、生活技能系统

### 核心原则

> **“24小时，你说了算。挂什么，练什么，没人管你。”**


### 技能分类（按控制方式）

> **“采集靠时间，制造靠材料，材料靠掉率。”**

| 类别 | 技能 | 控制方式 | 核心瓶颈 |
|------|------|----------|----------|
| **采集类** | 采矿、采药、种植织布、种植烹饪、剥皮 | **时间** | 挂机时长 + 技能等级 |
| **制造类** | 冶炼、裁缝、制皮、烹饪、炼金 | **材料** | 采集产出 + 怪物掉落 |

> **核心逻辑**：采集类技能永远在“转”，只要你挂机就有产出，效率由等级决定。制造类技能你随时可以做，但**有没有材料**是唯一限制——材料的来源又由采集效率和怪物掉率共同决定。


### 采集类技能：时间控制

> **“时间花在哪里，哪里就有收获。”**

#### 核心规则

| 规则 | 说明 |
|------|------|
| 控制变量 | **时间**（挂机/手动时长） |
| 产出频率 | 由技能等级决定（耗时递减） |
| 产出质量 | 由技能等级决定（解锁高级材料） |
| 产出数量 | 由时间决定（循环次数） |
| 唯一成本 | 时间本身 |

#### 采集类技能一览

| 技能 | 基础耗时 | 产出物 | 高级解锁条件 |
|------|----------|--------|-------------|
| 采矿 | 20s | 石头、铁矿石 | Lv.4→铜矿，Lv.7→银矿 |
| 采药 | 25s | 野草、基础药材 | Lv.4→珍稀草药，Lv.7→灵草 |
| 种植织布 | 60s | 亚麻 | Lv.4→棉花，Lv.7→丝绸 |
| 种植烹饪 | 60s | 小麦、蔬菜 | Lv.4→香料，Lv.7→特殊作物 |
| 剥皮 | 15s | 兽皮、兽骨 | Lv.3→精英皮，Lv.6→龙类皮 |

#### 通用规则

所有采集类技能遵循以下统一规则：

| 规则项 | 说明 |
|--------|------|
| 每个采集循环 | 消耗固定**基础时间**，产出一次材料 |
| 技能等级影响 | 等级越高，单次循环耗时越短 |
| 成功率 | 每次采集有概率失败，失败不产出材料 |
| 技能等级影响 | 等级越高，成功率越高 |
| 挂机收益 | 挂机时按当前等级耗时与成功率**自动循环执行** |

#### 耗时公式

> **实际耗时 = 基础耗时 ÷ (1 + 技能等级 × 0.10)**

| 技能等级 | 1级耗时 | 5级耗时 | 7级耗时 | 10级耗时 |
|----------|---------|---------|---------|----------|
| 采矿（基础20s） | 20.0s | 13.3s | 11.8s | 10.0s |
| 采药（基础25s） | 25.0s | 16.7s | 14.7s | 12.5s |
| 剥皮（基础15s） | 15.0s | 10.0s | 8.8s | 7.5s |
| 种植（基础60s） | 60.0s | 40.0s | 35.3s | 30.0s |

> 最小耗时下限：**1秒**（防止无限趋近于0）

#### 成功率公式

> **成功率 = min(80%, 30% + 技能等级 × 5%)**

| 技能等级 | 成功率 |
|----------|--------|
| 1级 | 35% |
| 3级 | 45% |
| 5级 | 55% |
| 7级 | 65% |
| 10级 | 80%（上限） |

> **设计意图**：永远存在20%的失败率，让采集保留一丝不确定性。高级别玩家可以信赖但无法完全依赖。

#### 失败反馈

- 采集失败时提示：`“你挥了个空。什么都没采到。”`
- 挂机结算时汇总：`“共尝试XX次，成功XX次，失败XX次。”`

#### 时间效率表

| 技能等级 | 单次耗时 | 每小时循环次数 | 每小时经验（约） |
|----------|----------|---------------|-----------------|
| Lv.1 | 基础值 | 约120-240次 | 300-500 EXP |
| Lv.3 | -25% | 约160-320次 | 500-800 EXP |
| Lv.5 | -40% | 约200-400次 | 800-1,200 EXP |
| Lv.7 | -55% | 约240-480次 | 1,200-1,800 EXP |
| Lv.10 | -70% | 约330-660次 | 2,000-3,000 EXP |


### 制造类技能：材料控制

> **“手艺摆在那里。有没有材料，决定了你做不做得出来。”**

#### 核心规则

| 规则 | 说明 |
|------|------|
| 控制变量 | **材料库存** |
| 制作条件 | 消耗指定材料 + 对应技能等级 |
| 制作耗时 | **瞬间完成**（不消耗挂机时间） |
| 产出数量 | 1:1 或 1:N（配方决定） |
| 核心瓶颈 | 材料的获取速度（采集效率 + 掉率） |

#### 制造类技能一览

| 技能 | 所需材料（来源） | 产出 | 材料瓶颈 |
|------|-----------------|------|----------|

| 制皮 | 皮革（剥皮）+ 骨（掉落） | 皮甲 | 剥皮效率 + 掉落率 |
| 烹饪 | 食材（种植烹饪）+ 肉（野兽掉落） | 食物增益 | 种植效率 + 掉落率 |
| 炼金 | 药材（采药）+ 特殊材料（掉落） | 药水/药剂 | 采药效率 + 掉落率 |

#### 闭环特征

| 特征 | 说明 |
|------|------|
| 上游（采集） | 时间驱动，永不枯竭，效率随等级提升 |
| 中游（制造） | 材料驱动，消耗上游产出，瞬间完成 |
| 下游（装备/消耗品） | 直接作用于战斗，形成价值闭环 |
| 外部输入（掉落） | 怪物掉率作为稀缺材料补充，调节经济平衡 |

## 十六、挂机系统

### 核心原则

> **“挂机 = 停留在某一帧，重复单一动作。转场、切换、决策，必须由玩家亲手做。”**

### 基本规则

| 规则 | 说明 |
|------|------|
| 挂机位置 | 玩家必须**身处某一帧** |
| 挂机动作 | 在该帧可执行的**单一动作** |
| 挂机时长 | 最多8小时 |
| 自动转场 | **不允许** |
| 自动切换动作 | **不允许** |

### 可挂机动作

- 采矿/伐木/采药
- 刷野兽/类人怪/机械守卫
- 锻造/冶炼/裁缝/制皮/烹饪/炼金
- 训练技能

### 挂机采集的循环逻辑

挂机采集时，系统按以下逻辑自动循环：

```
1. 计算当前技能等级 → 实际耗时
2. 计算当前技能等级 → 成功率
3. 开始计时（实际耗时）
4. 计时结束 → 判定成功率
   ├── 成功 → 获得材料 + 获得技能经验
   └── 失败 → 仅获得少量技能经验（成功经验的20%）
5. 进入下一循环
6. 重复直至挂机结束或背包满
```

### 挂机结算界面

```
┌───────────────────────────────────────────────────────────┐
│  ⛏️ 挂机结束 · 采矿                                      │
│  挂机时长：4小时17分                                     │
│  当前等级：采矿 Lv.3（匠人）                            │
│  下一级需：7,200 EXP                                    │
│                                                          │
│  总尝试次数：937次                                       │
│  成功次数：312次（成功率 33.3%）                        │
│  失败次数：625次                                         │
│                                                          │
│  获得：铁矿石×312                                        │
│  技能经验：+1,248 EXP                                   │
│  ▶ 经验进度：███░░░░░░ 17% → Lv.4                      │
│                                                          │
│  “你离大师之境，又近了一步。”                          │
├───────────────────────────────────────────────────────────┤
│                    [确认]                                │
└───────────────────────────────────────────────────────────┘
```

- 结算界面提示：“你已至当前极限。技艺仍可精进，但无法继续成长。”

## 三十一、UI画面设计

### 设计原则

> **“文字是主角，UI是容器。不抢戏，不炫技，不干扰阅读。”**


### UI设计总纲

> **“上方指路，下方历事，战斗另起一页。”**

#### 画面分区逻辑

| 区域 | 内容 | 交互方式 |
|------|------|----------|
| **顶部** | 小地图/当前位置指引 | 点击可移动、访问已知地点 |
| **中部** | 当前帧的叙事描述 + 可执行操作按钮 | 点击触发动作 |
| **底部** | 主菜单（背包/装备/随从/存档等） | 点击切换 |

#### 移动与探索

- 顶部小地图列出当前区域可前往的地点
- 点击地点名称直接移动，**无加载、无切换黑屏**
- 已解锁地点显示为「可前往」，未解锁显示为「🔒」
- 当前所在帧高亮标识

#### 战斗触发方式

| 触发方式 | 说明 |
|----------|------|
| **主动开战** | 玩家点击「迎战XXX」按钮，新开战斗页面 |
| **被动应战** | 探索/移动时遭遇敌人，自动新开战斗页面 |

> **关键设计原则**：战斗不在冒险画面中展开，而是**激发新开一页**。战斗结束后关闭战斗页面，返回冒险画面，保持上下文不丢失。这个设计避免了画面拥挤，让战斗和探索各得其所。
