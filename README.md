《寻亲风云录》文字RPG - 基于 GDD v11.0 开发

## 项目结构

```
├── index.html              # 入口页面
├── app.js                  # 主游戏逻辑/事件路由
├── css/
│   └── style.css           # 样式表
├── core/
│   ├── data.js             # 静态数据定义（职业/装备/地图/NPC等）
│   ├── state.js            # 存档状态管理
│   └── utils.js            # 通用工具函数
├── systems/
│   ├── combat.js           # 战斗引擎（4系伤害/异常/速度/3v6）
│   ├── equipment.js        # 装备系统（80词条/承载限制/镶嵌附魔）
│   ├── inventory.js        # 背包与仓库系统
│   └── scene.js            # 场景/地图/帧系统
└── ui/
    └── renderer.js         # UI渲染系统
```

## 本地运行

直接用浏览器打开 `index.html` 即可，无需服务器。

## 技术栈

- 纯前端：HTML + CSS + Vanilla JS
- 存档：LocalStorage + JSON导出
- 响应式：支持桌面和移动端
